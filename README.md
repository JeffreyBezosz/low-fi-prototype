# Klikbaar leesprototype

Open `index.html` in je browser. Het prototype gebruikt gewone HTML, CSS en JavaScript en heeft geen installatie nodig.

- **Leerling** — kies een leesopdracht, lees de tekst, beantwoord de vragen en bekijk je score en antwoorden. Het dashboard toont Milans voortgang en het level van zijn monstertje.
- **Leerkracht** — bekijk de voorbeeldklas, wijzig de klasnaam of maak een leesopdracht met één meerkeuzevraag. Je vindt een toegevoegde opdracht bij **Leerling → Leesopdrachten**.
- **Ouder** — bekijk Emma’s level, recente resultaten en vooruitgang per week.

De klas en Emma’s voortgang gebruiken voorbeeldgegevens. De browser onthoudt de opdrachten die je toevoegt, Milans resultaten, onafgewerkte vragen en de klasnaam op hetzelfde toestel.
