# Klasmonster – klikbaar low-fi prototype

Open `index.html` in je browser. Het prototype gebruikt gewone HTML, CSS en JavaScript en heeft geen installatie nodig.

Gebruik de pijlen in de zwarte balk om alle schermen in volgorde te doorlopen, of klik op **Alle schermen** voor de lijst.

- **Leerling** — dashboard, monstertje, leesopdrachten, lezen, vragen, antwoorden, overzicht en voortgang.
- **Leerkracht** — dashboard, alle leerlingen, nieuwe leesopdracht, sjablonen en klasinstellingen.
- **Ouder** — Emma’s level, recente resultaten en vooruitgang per week.

De klas en Emma’s voortgang gebruiken voorbeeldgegevens. De browser onthoudt gepubliceerde opdrachten, concepten, Milans resultaten en de klasinstellingen op hetzelfde toestel.
